מקרי אק"ג אמיתיים - אתר סטטי
================================
התיקייה הזו היא האתר כולו: index.html ותיקיית ecg. אין שרת ואין מסד נתונים.
אפשר להעלות אותה כמו שהיא לכל שירות אירוח סטטי (Netlify, Cloudflare Pages, GitHub Pages).
קישורים ישירים לפרקים: ‎#ch-1 עד ‎#ch-6, ו-‎#random לכל המקרים בסדר אקראי.
ההתקדמות של כל משתמש נשמרת ב-localStorage בדפדפן שלו בלבד.

קרדיט: PTB-XL v1.0.3 (Wagner et al., PhysioNet 2022, https://doi.org/10.13026/kfzx-aw45), ברישיון CC BY 4.0.
